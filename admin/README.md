# Призначення ролі вчителя (адміністративна операція)

Цей файл призначено для **власника Firebase-проєкту HUB 56 Education** або уповноваженого адміністратора.

- `assign-teacher.mjs` використовує Firebase Admin SDK і Application Default Credentials.
- Виконання у браузері або на GitHub Pages неможливе.
- Права доступу мають дозволяти керування користувачами Firebase Authentication.
- Сценарій спочатку працює у режимі перевірки. Параметр `--apply` потрібен для реальної зміни.
- **Не завантажуйте** файли сервісних ключів, паролі, токени або журнали з персональними даними в репозиторій.
- UID береться лише з Firebase Console → Authentication → Users.
- Перевіряйте ідентичність користувача перед призначенням ролі.
- Custom Claims дозволяють ідентифікувати роль у токені, але захист Firestore потребує окремих правил; наші чинні правила deny-all не змінювати.
- Перед проведенням реальних занять потрібне додаткове тестування безпеки.
