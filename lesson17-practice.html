Умова. Створіть масив, елементами якого є цілі числа: 21, 40, 53, 17, 33, що вводяться з клавіатури. Виведіть масив на екран.

Рівень складності

Алгоритм побудови програми — пишемо код самостійно

Читайте пояснення та самостійно вводьте кожен рядок у порожнє поле. У кінці формується повна програма.

  1. Крок 1. Підготуйте порожній список

    Запишіть змінну numbers, потім оператор присвоєння = і порожні квадратні дужки []. Список наповнюватиметься під час введення.

    Приклад рядка коду:

    numbers = []
  2. Крок 2. Організуйте п’ять повторень

    Почніть рядок із ключового слова for, далі запишіть змінну-лічильник i, слово in та функцію range(5). Аргумент 5 означає п’ять повторень із значеннями i від 0 до 4. Наприкінці поставте двокрапку.

    Приклад рядка коду:

    for i in range(5):
  3. Крок 3. Введіть і перетворіть чергове число

    Почніть із відступу в чотири пробіли, далі value =. Функція input() виводить текст і читає введене як рядок; зовнішня функція int() перетворює цей рядок на ціле число. У дужках input() використайте форматований f-рядок f"Введіть {i + 1}-й елемент: ". Вираз у фігурних дужках показує номери від 1 до 5. На першому проході буде показано дослівно «Введіть 1-й елемент: ».

    Приклад рядка коду:

        value = int(input(f"Введіть {i + 1}-й елемент: "))
  4. Крок 4. Додайте число до списку

    Зробіть такий самий відступ у чотири пробіли. Запишіть ім’я списку numbers, крапку та метод append(). Усередині дужок передайте змінну value, що містить поточне введене ціле число. На кожному проході воно додається в кінець списку.

    Приклад рядка коду:

        numbers.append(value)
  5. Крок 5. Виведіть усі п’ять чисел

    Пишіть без відступу, поза циклом. Викличте функцію print(); усередині дужок запишіть два аргументи: пояснювальний рядок "Масив:" і змінну numbers, відокремлені комою.

    Приклад рядка коду:

    print("Масив:", numbers)

Умова. Створіть масив, елементами якого є 10 випадкових чисел у діапазоні від 4 до 10. Виведіть масив на екран.

Рівень складності

Алгоритм побудови програми — пишемо код самостійно

Читайте пояснення та самостійно вводьте кожен рядок у порожнє поле. У кінці формується повна програма.

  1. Крок 1. Підключіть модуль

    На початку програми запишіть ключове слово import та назву модуля random. Модуль містить функції для отримання випадкових значень.

    Приклад рядка коду:

    import random
  2. Крок 2. Створіть порожній список

    Запишіть змінну numbers, оператор присвоєння = та порожні квадратні дужки []. У цьому списку зберігатимуться десять чисел.

    Приклад рядка коду:

    numbers = []
  3. Крок 3. Організуйте десять повторень

    Введіть цикл for i in range(10):. Ключові слова for та in організовують перебір; змінна i набуває значень 0–9. Функція range() отримує аргумент 10. Не забудьте двокрапку.

    Приклад рядка коду:

    for i in range(10):
  4. Крок 4. Отримайте випадкове ціле число

    Зробіть відступ чотири пробіли; записуйте value =. Далі використайте функцію randint() модуля random: у круглих дужках два аргументи, 4 і 10, задають обидві включені межі випадкового цілого числа.

    Приклад рядка коду:

        value = random.randint(4, 10)
  5. Крок 5. Збережіть поточне значення

    Зробіть той самий відступ. Викличте метод numbers.append(value): через крапку після імені списку запишіть append, а в круглих дужках — поточне число value.

    Приклад рядка коду:

        numbers.append(value)
  6. Крок 6. Виведіть отриманий масив

    Без відступу запишіть print("Масив:", numbers). Усередині дужок функції print() є текстовий аргумент "Масив:" і змінна списку numbers, розділені комою.

    Приклад рядка коду:

    print("Масив:", numbers)

Завдання 4

Умова. Створіть масив, елементами якого є 5 перших членів арифметичної прогресії. Перший член 3, а різниця 4. Виведіть масив на екран.

Рівень складності

Алгоритм побудови програми — пишемо код самостійно

Читайте пояснення та самостійно вводьте кожен рядок у порожнє поле. У кінці формується повна програма.

  1. Крок 1. Задайте перший член

    Запишіть змінну first, оператор присвоєння = та ціле число 3 — перший член прогресії.

    Приклад рядка коду:

    first = 3
  2. Крок 2. Задайте різницю прогресії

    Запишіть змінну step, оператор = і число 4. Різниця арифметичної прогресії показує, на скільки кожний наступний член більший від попереднього.

    Приклад рядка коду:

    step = 4
  3. Крок 3. Створіть список для членів прогресії

    У змінну progression за допомогою = запишіть порожній список [], куди додаватимуться обчислені числа.

    Приклад рядка коду:

    progression = []
  4. Крок 4. Організуйте цикл

    Уведіть for i in range(5):. Змінна-лічильник i набуває значень 0, 1, 2, 3, 4. Двокрапка означає початок тіла циклу.

    Приклад рядка коду:

    for i in range(5):
  5. Крок 5. Обчисліть черговий член

    З чотирма пробілами відступу запишіть value = first + i * step. Оператор * множить номер кроку на різницю прогресії, а + додає отримане до першого члена. За i = 0 результат — 3.

    Приклад рядка коду:

        value = first + i * step
  6. Крок 6. Додайте обчислене значення

    У тому самому тілі циклу з відступом викличте метод progression.append(value); аргумент value — щойно обчислений член прогресії.

    Приклад рядка коду:

        progression.append(value)
  7. Крок 7. Виведіть результат

    Поза циклом викличте функцію print(), передайте текст "Масив:" і змінну progression через кому.

    Приклад рядка коду:

    print("Масив:", progression)

Моя програма — зібраний код

Введіть усі рядки й перевірте програму.

Перевірка зіставляє введену програму з еталонними рядками; код Python у браузері не виконується.

Типова помилка та її виправлення
    value = first + (i + 1) * step

Оскільки i починається з нуля, додавання одиниці пропускає перший член 3. Правильно: first + i * step.

Очікуваний результат: Масив: [3, 7, 11, 15, 19]

Переглянути повний правильний код
first = 3
step = 4
progression = []
for i in range(5):
    value = first + i * step
    progression.append(value)
print("Масив:", progression)
