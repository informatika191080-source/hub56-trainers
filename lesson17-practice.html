ЗАВДАННЯ 1 ІЗ 4

Список слів

Створіть список зі слів «звук», «колонка», «кодування», «модель» та виведіть його.

Покрокова побудова

  1. Створіть змінну words.
  2. У квадратних дужках через кому запишіть чотири рядки в лапках.
  3. Виведіть список функцією print(words).
Показати правильний повний код
words = ["звук", "колонка", "кодування", "модель"]
print(words)
ЗАВДАННЯ 2 ІЗ 4

П’ять цілих чисел

Послідовно введіть числа 21, 40, 53, 17, 33 з клавіатури та виведіть список.

Покрокова побудова

  1. Створіть порожній список numbers = [].
  2. Цикл for i in range(5): виконується п’ять разів.
  3. Функція input() показує «Введіть елемент: » і читає текст. int() перетворює введення на ціле число.
  4. Метод numbers.append(value) додає число до списку; команда записується з відступом у циклі.
  5. Після завершення циклу print(numbers) показує готовий список.
Показати правильний повний код
numbers = []
for i in range(5):
    value = int(input("Введіть елемент: "))
    numbers.append(value)
print(numbers)
ЗАВДАННЯ 3 ІЗ 4

Десять випадкових чисел

Створіть список із 10 випадкових цілих чисел від 4 до 10 включно.

Покрокова побудова

  1. Підключіть модуль import random.
  2. Створіть порожній список numbers.
  3. Повторіть 10 разів виклик random.randint(4, 10): він повертає ціле число від 4 до 10 включно.
  4. Додайте число методом append() та після циклу виведіть весь список.
Показати правильний повний код
import random
numbers = []
for i in range(10):
    x = random.randint(4, 10)
    numbers.append(x)
print(numbers)
ЗАВДАННЯ 4 ІЗ 4

Арифметична прогресія

Складіть список перших п’яти членів прогресії з першим членом 3 і різницею 4.

Покрокова побудова

  1. Задайте first = 3 і step = 4.
  2. Створіть порожній список progression.
  3. Цикл for i in range(5) перебирає індекси від 0 до 4.
  4. Вираз first + i * step обчислює черговий член.
  5. append() додає значення до списку. Очікуємо [3, 7, 11, 15, 19].
Показати правильний повний код
first = 3
step = 4
progression = []
for i in range(5):
    value = first + i * step
    progression.append(value)
print(progression)
