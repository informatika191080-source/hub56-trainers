Операційні системи

Операційна система (ОС) — це базовий комплекс взаємопов'язаних системних програм, призначений для:

  • Керування роботою фізичних та віртуальних пристроїв комп'ютера.
  • Організації збереження даних на зовнішніх носіях (дисках, картах пам'яті).
  • Запуску інших програм (прикладного ПЗ та систем програмування) на виконання.
  • Забезпечення безпечного та зручного обміну даними між користувачем та комп'ютером (інтерфейс).

Складові операційної системи

Основні структурні компоненти, з яких складається сучасна ОС:

BIOS (або UEFI) — базова система введення-виведення: апаратно інтегрований набір мікропрограм для перевірки працездатності пристроїв під час увімкнення комп'ютера та ініціалізації завантаження ядра операційної системи.

Ядро операційної системи: основна частина ОС, що виконує системні команди, розподіляє ресурси пам'яті та каналів зв'язку між пристроями й програмами, забезпечує стабільність роботи комп'ютера.

Файлова система: структура збереження даних на зовнішніх накопичувачах та сукупність програм для роботи з цією структурою. Поширені файлові системи: NTFS, FAT16, FAT32 у Windows; ext4 у Linux; APFS у macOS.

Драйвери пристроїв: спеціальні керуючі програми для узгодження обміну даними між операційною системою та конкретними моделями фізичних пристроїв (відеокартами, принтерами, клавіатурами тощо).

Інтерфейс користувача: сукупність засобів і правил, які забезпечують обмін даними між користувачем та операційною системою. Буває текстовим (командний рядок, CLI) або графічним (вікна, іконки, меню, GUI).

Класифікація ОС за призначенням

Залежно від цільових пристроїв та умов експлуатації операційні системи поділяють на такі великі групи:

Група ОС за призначеннямПриклади та особливості функціонування
Для стаціонарних персональних комп'ютерівWindows 11, macOS (OS X), Linux, Chrome OS.
Для мобільних комп'ютерів та смартфонівAndroid, iOS, KaiOS, Tizen.
Для серверів та суперкомп'ютерівUnix, Linux, Windows Server, Solaris.
Для різноманітних вбудованих комп'ютерівFreeRTOS, ADAS, Embedded Linux, OpenWrt, VxWorks.

Класифікація ОС за типом ліцензії

За типом ліцензії, яка визначає умови розповсюдження та використання системи, ОС поділяють на:

Комерційні (пропрієтарні) — використання вимагає обов'язкової купівлі ліцензійного ключа, вихідний програмний код закритий для користувачів та розробників (наприклад, Windows, macOS).

Пробні (trial) — операційні системи чи системні компоненти, які надають повний або дещо обмежений функціонал безкоштовно протягом короткого ознайомчого періоду.

Вільні / Відкриті (Free Software / Open-Source) — розповсюджуються безкоштовно, вихідний програмний код відкритий для будь-яких користувачів, які мають право вносити зміни та покращувати систему (наприклад, ОС сімейства Linux, Android).

Класифікація ОС за розрядністю

Розрядність операційної системи вказує на розрядність центральних процесорів комп'ютера, для підтримки яких вона адаптована:

64-розрядні операційні системи (x64) — сучасний стандарт комп'ютерних обчислень. Вони здатні швидко та ефективно обробляти великі обсяги інформації та підтримувати понад 4 ГБ оперативної пам'яті (RAM). Встановлюються виключно на 64-розрядні процесори.

32-розрядні операційні системи (x86) — застарілий стандарт. Вони мають апаратне обмеження — не здатні «бачити» та використовувати понад 4 ГБ оперативної пам'яті комп'ютера, навіть якщо встановлено більше. Процесори такої архітектури останніми роками майже не випускаються.

Важливо! 64-розрядна операційна система фізично НЕ може бути встановлена на комп'ютер із застарілим 32-розрядним процесором! У той же час 32-розрядна ОС може бути встановлена на 64-розрядну архітектуру, проте вона суттєво обмежить працездатність процесора.

Сумісність програмного забезпечення

Сумісність ПЗ — це здатність програмного продукту запускатися, коректно працювати та взаємодіяти з операційною системою та апаратним забезпеченням конкретного комп'ютера.

Оскільки комп'ютерні програми створюються розробниками під вимоги конкретної операційної системи, програми для однієї ОС є несумісними з іншими типами систем.

Кросплатформність

Кросплатформне програмне забезпечення — це програми, версії яких створені для використання на кількох різних операційних системах.

Яскравим прикладом є браузер Google Chrome чи клієнт Skype. Для користувача їхній графічний інтерфейс та функції виглядають майже однаково на різних операційних системах.

Сумісність версій

Сумісність програмного забезпечення може бути порушена навіть між різними версіями однієї операційної системи:

Зворотна сумісність — здатність сучасної версії операційної системи успішно запускати та працювати з програмами, розробленими для попередніх застарілих версій.

Пряма несумісність — ситуація, коли застаріла версія ОС не може запустити нове прикладне програмне забезпечення через відсутність у старій системі необхідних сучасних функцій, драйверів, оновлень безпеки та бібліотек.

Службове ПЗ (Утиліти)

Утиліти (від англ. utility — корисність) — це допоміжні службові програми, які призначені для діагностування апаратної та програмної складових комп'ютера, розширення можливостей ОС та налаштування, очищення й оптимізації роботи системи.

Службові програми в Windows 11

Під час встановлення (інсталяції) ОС Windows 11 на комп'ютер у систему інтегрується набір корисних утиліт:

  • Диспетчер завдань (Task Manager) — програма для моніторингу завантаженості процесора, оперативної пам'яті, дисків та контролю запущених процесів, а також примусового завершення програм у разі їх зависання.
  • Оптимізація дисків (Optimize Drives) — утиліта для дефрагментації традиційних жорстких дисків (HDD) або оптимізації твердотільних накопичувачів (SSD) для підвищення швидкодії роботи із даними.
  • Registry Editor (Редактор реєстру) — складна системна програма для внесення ручних змін у глобальну базу конфігураційних налаштувань операційної системи та встановлених програм (Реєстр Windows).
  • System Configuration (Конфігурація системи) — утиліта для тонкого налаштування режимів запуску комп'ютера, служб та керування списком автозавантаження програм.
  • Панель керування (Control Panel) — традиційний єдиний інтерфейс для налаштування абсолютно всіх параметрів ПК (доступ: Пуск ⇒ Усі ⇒ Інструменти Windows ⇒ Панель керування).

Службове ПЗ в інших операційних системах

Подібний набір базових службових програм обов'язково інтегрований і в інші операційні системи:

В операційній системі Linux Ubuntu: Менеджер архівів (стиснення та розпакування архівів), Журнал системи (перегляд логів та помилок), Аналізатор використання диска, Системний монітор (аналог Диспетчера завдань), Диски (керування розділами).

В операційній системі Android: Диспетчер файлів (провідник для керування внутрішньою та зовнішньою пам'яттю), Календар, Хмарний Диск (Google Drive), Android Auto, Системні налаштування.

Драйвери та технологія Plug and Play

Драйвер (від англ. driver — водій) — спеціальна службова утиліта, яка забезпечує безпомилковий обмін даними між операційною системою та конкретною моделлю підключеного комп’ютерного пристрою (клавіатури, сканера, відеокарти, принтера, монітора тощо).

Технологія Plug and Play (увімкни та працюй) — апаратно-програмна функція сучасних ОС, яка автоматично розпізнає новий підключений пристрій, знаходить для нього потрібний драйвер у локальній базі чи в інтернеті та налаштовує його роботу за кілька секунд.

Де шукати драйвери?

Якщо автоматичний пошук Plug and Play не спрацював, драйвери можна знайти такими способами:

Автоматично через інтернет: ОС за наявності мережевого підключення звертається до офіційної хмарної бази оновлень (наприклад, Windows Update від Microsoft) та інсталює актуальну сертифіковану версію драйвера.

Ручне встановлення: завантаження драйвера виключно з офіційного сайту виробника конкретного пристрою (HP, Canon, Nvidia, Intel, Samsung) або встановлення за допомогою інсталяційного диска чи флеш-накопичувача, який постачався разом із пристроєм в оригінальній коробці.
