Списки в Python: створення та виведення

Навчимося створювати списки, звертатися до елементів за індексом, вводити й виводити дані. Розбиратимемо кожну команду на конкретних прикладах і перевірятимемо результат у практичних вправах.

1. Що таке список і для чого він потрібний?

Уявімо, що нам потрібно зберегти ціни восьми товарів. Можна створити вісім окремих змінних, але це незручно: доведеться окремо звертатися до кожного значення. Список дозволяє об'єднати ці значення під одним ім'ям і послідовно опрацьовувати їх.

Список (list) — впорядкована змінювана послідовність елементів. Елементи можуть мати різні типи даних, але в наших навчальних задачах переважно використовуються числа. Впорядкованість означає, що кожен елемент має своє місце; змінюваність — що значення можна замінювати та додавати нові елементи.

a = [4, -3.8, 0, 3.5, -4, 5.1, -2]

Розбираємо запис зліва направо:

  1. a — ім'я змінної, яка посилається на список.
  2. = — оператор присвоювання.
  3. [ ] — квадратні дужки, між якими записані елементи; коми розділяють значення.

У цьому списку сім елементів.

Індекси: чому перший елемент має номер 0?

Індекс — номер позиції елемента у списку. У Python відлік починається з нуля: перший елемент має індекс 0, другий — 1, останній із семи — 6. Запис a[2] означає «взяти зі списку a елемент з індексом 2»; це число 0.

a = [4, -3.8, 0, 3.5, -4, 5.1, -2]
a[5] = 3

2. Функції та методи: окремий приклад для кожної команди

Функція — іменована операція, яку можна викликати для виконання певної дії та, за потреби, отримання результату. Метод — операція, яку викликають у певного об'єкта, наприклад списку. У записі a.append(40) метод append() викликається для списку a. Значення в круглих дужках називають аргументом.

2.1. Функція len() — визначення кількості елементів

a = [10, 20, 30]
n = len(a)
print(n)

Рядок 1. Створюємо список a із трьох чисел. Рядок 2. У виклик len(a) передаємо як аргумент список a. Функція підраховує елементи й повертає число 3. Оператор = присвоює це число змінній n. Рядок 3. print(n) показує отримане значення.

Результат: 3

Важливо: кількість елементів — 3, але індекси цього списку — 0, 1 і 2. Не плутайте кількість з останнім індексом.

2.2. Метод append() — додавання елемента в кінець

a = [10, 20, 30]
a.append(40)
print(a)

Рядок 1. Створюємо список із трьох чисел. Рядок 2. Пишемо ім'я списку a, крапку, назву методу append та круглі дужки. Усередині дужок записуємо 40 — елемент, який потрібно додати. Рядок 3. Виводимо список після зміни.

Результат: [10, 20, 30, 40]

Метод append() додає один елемент наприкінці списку. Він змінює сам список; не потрібно записувати a = a.append(40).

2.3. Функція print() — виведення списку або одного елемента

a = [10, 20, 30]
print(a)
print(a[0])

Рядок 1. Створюємо список. Рядок 2. Передаємо до print() список a цілком — Python показує квадратні дужки й коми. Рядок 3. Передаємо тільки a[0], тобто елемент з індексом нуль.

Результат на двох рядках:
[10, 20, 30]
10

2.4. print(*a) — виведення елементів через пропуски

a = [10, 20, 30]
print(*a)

Символ * перед ім'ям списку a розпаковує його елементи в окремі аргументи функції print(). За замовчуванням print() ставить між аргументами пропуски. Результат: 10 20 30 — без квадратних дужок і ком.

2.5. Введення значень по одному: input(), float() і append()

a = []
for i in range(3):
    x = float(input("Уведіть значення елемента списку > "))
    a.append(x)
print(a)

Алгоритм введення по одному числу:

  1. a = [] — створюємо порожній список.
  2. for i in range(3): — повторюємо введення тричі. Індекси циклу: 0, 1, 2.
  3. input("Уведіть значення елемента списку > ") — показує підказку й читає текст. float() перетворює його на число, яке присвоюємо змінній x.
  4. a.append(x) — додаємо число до кінця списку; команда має відступ усередині циклу.
  5. print(a) — після завершення циклу виводимо список.

Якщо послідовно ввести 4, 5.3, 12, результатом буде [4.0, 5.3, 12.0]. Тут натискання Enter потрібне після кожного числа.

2.6. Введення одного рядка: split(), map(), list()

a = list(map(float, input("Уведіть довжини сторін квадратів > ").split()))
print(a)

Спочатку input() зчитує весь рядок. Потім метод split() розділяє його на частини за пропусками. Функція map(float, ...) застосовує перетворення float до кожної частини. Функція list(...) збирає перетворені числа в список, який оператор = присвоює змінній a. Нарешті, print(a) виводить результат.

Наприклад, введення 4 5.3 12 створить список [4.0, 5.3, 12.0]. На відміну від попереднього способу, всі значення вводяться відразу через пропуски.

Обмеження: ця версія не виконує Python-код. Вона перевіряє відповіді на заздалегідь визначені завдання у браузері. Оцінки не записуються, особисті дані не збираються, Firestore не використовується.
