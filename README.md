# HUB 56 — інтерактивний простір інформатики

Україномовна навчальна вебплатформа для учнів **5–9 класів**, розроблена для гімназії №56. Проєкт перебуває на етапі пілотного впровадження.

**Сайт:** https://informatika191080-source.github.io/hub56-trainers/

## Навігація та організація матеріалів

Стандарт платформи: **Головна → Клас → Урок → Розділ уроку**.

- [Головна сторінка](index.html) містить вибір класів.
- [5 клас](class5.html), [6 клас](class6.html), [7 клас](class7.html), [8 клас](class8.html) — каталоги, матеріали яких наразі готуються.
- [9 клас](class9.html) — каталог із доступним [уроком №18](pilot-lesson18.html).
- Усередині навчального простору показано навігацію **лише поточного класу**. Зміна класу здійснюється через головну сторінку, доступну за логотипом HUB 56.
- Навігація учнівських сторінок уніфікована у `js/student-nav.js` та `css/student-nav.css`; для вузьких екранів передбачено компактне меню.
- Кабінет учителя відокремлено від навігації учнів.

Мета — поступово наповнювати каталоги відповідно до навчальних планів, орієнтовно до **70 уроків на клас**. Це ціль наповнення, а не кількість уже опублікованих уроків.

## Доступні навчальні матеріали

**9 клас, урок №18 — «Списки в Python: створення та виведення списків»:**

- [Меню уроку](pilot-lesson18.html)
- [Теорія та мініпрактики](lesson18-theory.html)
- [Контрольні питання](lesson18-questions.html) — 5 запитань з перевіркою та поясненнями.
- [Практичні завдання](lesson18-practice.html) — 4 покрокові тренажери з двома рівнями складності, складанням рядків програми, перевіркою структури та повідомленнями про помилки.
- [Інтерактивна вправа](lesson18-interactive.html) — зовнішня вправа Wordwall; QR-код зберігається локально в `assets/wordwall-lesson18-qr.svg`.
- [Домашнє завдання](lesson18-homework.html).

**Важливо:** тренажери перевіряють відповідність рядків коду заданому навчальному алгоритму, але **не виконують Python-програми** та не є повноцінним Python-інтерпретатором. Приймання коду не гарантує правильність будь-якої довільної програми.

## Вхід і кабінет учителя

- [Сторінка входу](login.html) використовує Firebase Authentication з входом за електронною поштою й паролем.
- [Кабінет учителя](teacher.html) — демонстраційний інтерфейс. У клієнтському коді роль учителя перевіряється за `role === "teacher"` у Firebase ID token.
- Інтерфейс кабінету містить вкладки та демонстраційні елементи; **реальний журнал оцінок, учнівські результати й перегляд роботи учнів у реальному часі не підключені**.
- Наявність перевірки ролі в браузері **не є доказом захисту серверних даних**. Перед роботою з реальними учнівськими даними необхідно окремо перевірити й налаштувати правила доступу Firebase/Firestore.

## Розміщення та перевірка

Сайт опубліковано через **GitHub Pages**. Це статичний вебпроєкт із клієнтським JavaScript та інтеграцією Firebase для входу.

Після змін потрібно перевіряти публічну версію сайту після оновлення GitHub Pages:

1. Головна → потрібний клас → урок → розділ → повернення до каталогу того самого класу.
2. Навігація клавіатурою, активний розділ і мобільне меню.
3. Чотири практичні тренажери: правильний/неправильний код, відступи, повідомлення про помилки.
4. Контрольні питання: результат і скидання після зміни відповіді.
5. Зовнішню вправу Wordwall і сканування QR-коду.
6. Реальне відображення на мобільних ширинах — **ще потребує окремого завершеного тестування**.
7. Авторизовані сценарії кабінету вчителя — **потребують окремої перевірки тестовим обліковим записом із відповідною роллю**.

## Що ще розробляється

- Наповнення уроками 5–9 класів.
- Python Lab із реальним запуском Python.
- Постійні облікові записи учнів і збереження прогресу.
- Перевірене серверне зберігання результатів, оцінювання та спостереження вчителя в реальному часі.
- Подальші інтерактивні аркуші, тренажери та віртуальні лабораторії.

## Безпека й авторство

Не публікуйте в репозиторії паролі, секретні ключі, персональні дані учнів чи приватні результати. Публічна Firebase web configuration — не адміністративний ключ; доступ до даних має визначатися правилами безпеки на сервері.
