# HUB 56 — Інтерактивний простір інформатики

Навчальна вебплатформа для учнів 5–9 класів.

## Поточний стан
Створено демонстраційну головну сторінку з каталогом класів та напрямів навчання. Облікові записи, завдання, оцінювання й Python Lab поки не підключені.

## Файли
- `index.html` — головна сторінка;
- `css/style.css` — адаптивний дизайн;
- `js/app.js` — формування каталогу класів.

## Безпека
Не завантажуйте в цей публічний репозиторій персональні дані учнів, паролі або секретні ключі.

## Наступний крок
Налаштувати GitHub Pages і перевірити сторінку на комп'ютері та смартфоні.
