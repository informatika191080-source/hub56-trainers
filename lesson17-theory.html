Теорія

Поняття одновимірного масиву

Навіщо потрібні масиви?

У багатьох задачах опрацьовують багато пов’язаних значень: температуру за кілька днів, оцінки, ціни товарів. Замість великої кількості окремих змінних зручніше використовувати один упорядкований набір.

Одновимірний масив — впорядкований за номерами набір змінних одного типу зі спільним ім’ям.

Елемент, індекс, значення

Елемент — окрема складова масиву; індекс — позиція елемента; значення — дані, які зберігаються в цьому елементі.

a = [4, -3.8, 0, 3.5, -4, 5.1, -2]
4a[0]
-3.8a[1]
0a[2]
3.5a[3]
-4a[4]
5.1a[5]
-2a[6]

У Python перший елемент має індекс 0. Якщо у списку N елементів, останній невід’ємний індекс — N − 1.

Індексом може бути ціле число a[0], змінна a[i] чи цілочисельний вираз a[2*i + 3]. Індекс повинен вказувати на наявний елемент.

Списки Python

Для практичних задач використовуватимемо списки Python. Їхні елементи записуються у квадратних дужках і відокремлюються комами.

a = [4, -3.8, 0, 3.5, -4, 5.1, -2]
print(a)
print(a[0])

print(a) виводить увесь список, а print(a[0]) — значення першого елемента (4).

Порожній список і метод append()

numbers = []
numbers.append(5)
numbers.append(-12)
numbers.append(7)
print(numbers)

[] створює порожній список. Метод append() додає один елемент у кінець списку. Отримаємо [5, -12, 7].

Масив і цикл

suma = 0
for i in range(100):
    suma = suma + a[i]

Змінна i послідовно приймає індекси від 0 до 99. На кожному повторенні до suma додається поточний елемент.

Для виконання цього фрагмента список a повинен містити щонайменше 100 елементів; це окремий приклад, не для списку із семи елементів вище.

Пам’ятайте

  • Квадратні дужки потрібні для списку й звернення за індексом.
  • Текстові значення записують у лапках; елементи розділяють комами.
  • Після for ... : ставлять двокрапку, а тіло циклу пишуть із відступом.
  • Не виходьте за межі наявних індексів.
