Завдання 1. Дослідіть інформаційну систему установи.

Умова. Дослідіть інформаційну систему установи.

Алгоритм виконання

  1. Крок 1.

    Оберіть одну з установ, наприклад:

    • Школа;
    • Магазин;
    • Поліклініка;
    • Автовокзал.
  2. Крок 2.

    Уявіть, що ви – фахівець, який має пояснити, як у цій організації працює інформаційна система. Підготуйте відповіді на запитання:

    • Які дані зберігаються в системі? (Наприклад, розклад уроків, список учнів, оцінки або товари, ціни, кількість на складі.)
    • Хто користується цією системою? (Учні, вчителі, касири, покупці тощо.)
    • Для яких цілей створена інформаційна система цієї установи? (Щоб зберігати інформацію, швидко знаходити дані, оформлювати покупки, рахувати оцінки тощо.)
  3. Крок 3.

    Для запису відповідей на запитання створіть у текстовому процесорі документ, у який уведіть запитання та відповіді на них.

  4. Крок 4.

    Збережіть створений документ у вашій папці у файлі з іменем вправа 1.1.

  5. Крок 5.

    Складіть у створеному текстовому документі таблицю, у яку введіть відповідні дані.

    Компонент ІСПриклади компонентів у обраній установі
    Апаратне забезпечення
    Програмне забезпечення
    Інформаційне забезпечення (дані)
    Користувачі

    Заповнюйте таблицю прямо на HUB 56. Введені дані автоматично зберігаються лише у браузері цього пристрою.

  6. Крок 6.

    Збережіть змінений документ у тому самому файлі.

  7. Крок 7.

    Створіть у створеному документі схему обміну даними між користувачами й інформаційною системою установи. Для побудови схеми використайте засоби створення графічних зображень текстового процесора.

  8. Крок 8.

    Збережіть змінений документ у тому самому файлі.

Контроль виконання

Позначте етапи, які вже виконано у текстовому процесорі.

Виконано 0 із 4 етапів.

Завдання 2. Дослідіть програмне забезпечення (у комп'ютерному класі або вдома).

Умова. Дослідіть програмне забезпечення (у комп'ютерному класі або вдома).

    Google Chrome
    Для створення графічних зображень
    Безпека у Windows
    Службове
    Для роботи з архівами даних

    Заповнюйте таблицю прямо на HUB 56. Введені дані автоматично зберігаються лише у браузері цього пристрою.

  4. Крок 4.

    Збережіть створений документ у вашій папці у файлі з іменем вправа 1.2.

Практична робота · Завдання 3

Завдання 3. Визначте тип ліцензії

Умова. Визначте тип ліцензії

Алгоритм виконання

  1. Крок 1.

    Відкрийте перелік програм, установлених на вашому комп'ютері, виконавши Пуск = Усі.

  2. Крок 2.

    Виберіть у цьому переліку чотири програми, що мають різні ліцензії. Про тип ліцензії можна дізнатися, виконавши відповідний запит в одній із пошукових систем або зробивши запит одному із сервісів ШІ, наприклад, такий: «Яку ліцензію має програма 7Z?»

  3. Крок 3.

    За результатами пошуку заповніть таблицю.

    ПрограмаТип ліцензіїЧому ти так вважаєш?
    Microsoft WindowsОЕМ комерційнаЄ відповідна наклейка на корпусі ноутбука

    Заповнюйте таблицю прямо на HUB 56. Введені дані автоматично зберігаються лише у браузері цього пристрою.

  4. Крок 4.

    Збережіть створений документ у вашій папці у файлі з іменем вправа 1.3.

Контроль виконання

Виконано 0 із 4 етапів.
